# 🔍 Skill: audit_code (QA 감사 및 자율 디버깅 스킬)

## 설명 (Description)
`app_build/` 내의 소스코드를 분석하여 구문 오류, 의존성 충돌, 런타임 결함 및 누락된 로직을 식별하고, 파일을 직접 덮어쓰며 자율 패치 루프를 수행합니다. 3회 실패 시 서킷 브레이커(Circuit Breaker)가 발동됩니다.

---

## 🎯 실행 절차 (Execution Workflow)

### 1단계: 정적 감사 및 결함 탐색
1. `app_build/` 내의 모든 소스코드에 대해 다음 항목을 전수 감사합니다:
   - **의존성 무결성**: `package.json` / `requirements.txt`에 명시된 패키지와 코드 내 `import`/`require` 구문의 일치 여부
   - **문법 및 린트**: TypeScript/JavaScript 구문 오류, 미선언 변수, 닫히지 않은 태그/괄호
   - **상태 관리 및 비동기 처리**: Promise 처리 누락, 렌더링 무한 루프 가능성
   - **경로 참조**: 에셋, 컴포넌트, 스타일시트 상대 경로 유효성

### 2단계: 정밀 타격 자율 패치 (In-place Rework Loop)
1. 결함 발견 시 해당 파일을 직접 수정(덮어쓰기)하여 패치합니다.
2. 디버깅 카운터를 1 증가시킵니다.

### 3단계: 안전장치 (3회 서킷 브레이커)
- **성공 시 (결함 0건)**: 즉시 **DevOps Master (@devops)**로 컨텍스트를 스위칭하고 `.agents/skills/deploy_app.md`를 호출합니다.
- **실패 지속 시 (3회 도달)**:
  - 무한 루프를 방지하기 위해 디버깅 루프를 즉시 중단(Circuit Breaker Triggered)합니다.
  - 현재까지 발생한 오류 내역, 시도한 수정 내역, 잔여 결함 목록을 상세히 정리하여 사용자에게 보고하고 제어권을 반환합니다.
