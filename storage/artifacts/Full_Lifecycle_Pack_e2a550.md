## Stage 4: 코다리 (시니어 풀스택 엔지니어)

### 💻 코다리 (시니어 풀스택 엔지니어) 관점:
충성! 대표님, 시니어 풀스택 엔지니어 코다리 부장입니다!

본 프로젝트의 요구사항에 따라 간단한 자동 홍보 플랫폼을 위한 웹사이트 소스코드를 작성해 드리겠습니다. 이 코드는 사용자가 GitHub 주소를 입력하면 해당 리포지토리의 정보를 읽어와서 연결된 SNS에 홍보하는 기능을 제공합니다.

아래는 HTML, CSS, JavaScript로 구성된 간단한 예제입니다:

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>자동 홍보 플랫폼</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            margin: 20px;
        }
        .container {
            max-width: 600px;
            margin: auto;
        }
        input[type="text"] {
            width: calc(100% - 22px);
            padding: 10px;
            margin-bottom: 10px;
        }
        button {
            padding: 10px 20px;
            background-color: #007BFF;
            color: white;
            border: none;
            cursor: pointer;
        }
        ul {
            list-style-type: none;
            padding: 0;
        }
        li {
            margin-bottom: 10px;
        }
    </style>
</head>
<body>
    <div class="container">
        <h1>자동 홍보 플랫폼</h1>
        <input type="text" id="githubUrl" placeholder="GitHub 주소를 입력하세요 (예: https://github.com/username/repo)">
        <button onclick="promoteOnSNS()">홍보하기</button>
        <ul id="snsList"></ul>
    </div>

    <script>
        async function promoteOnSNS() {
            const githubUrl = document.getElementById('githubUrl').value;
            if (!githubUrl) {
                alert('GitHub 주소를 입력해주세요.');
                return;
            }

            try {
                const response = await fetch(`https://api.github.com/repos${githubUrl.split('github.com')[1]}`);
                const repoData = await response.json();

                const snsList = document.getElementById('snsList');
                snsList.innerHTML = '';

                // 예제로 Twitter에 대한 홍보 추가
                const twitterItem = document.createElement('li');
                twitterItem.textContent = `Twitter: ${repoData.full_name} - ${repoData.description}`;
                snsList.appendChild(twitterItem);

                // 다른 SNS에 대한 추가 로직을 여기에 작성할 수 있습니다.

            } catch (error) {
                console.error('GitHub API 호출 중 오류 발생:', error);
                alert('GitHub 주소를 다시 확인해주세요.');
            }
        }
    </script>
</body>
</html>
```

### 1. 직무 전문 진단 및 인사이트
이 코드는 간단한 자동 홍보 플랫폼의 기본 구조를 제공합니다. 사용자가 GitHub 주소를 입력하면 해당 리포지토리의 정보를 읽어와서 Twitter에 대한 홍보 메시지를 생성합니다. 다른 SNS(예: Facebook, LinkedIn)에 대한 추가 로직을 작성하여 확장할 수 있습니다.

### 2. 구체적 실전 실행 액션 플랜
1. **GitHub API 호출**: 사용자가 입력한 GitHub 주소를 이용해 GitHub API를 호출하여 리포지토리 정보를 가져옵니다.
2. **SNS 홍보 메시지 생성**: 가져온 리포지토리 정보를 기반으로 SNS에 게시할 홍보 메시지를 생성합니다.
3. **화면 업데이트**: 홍보 메시지를 화면에 표시합니다.

### 3. 타 부서 협업 요청 포인트
- **API 통합 팀**: GitHub API 호출 로직을 최적화하고 다른 SNS API와의 연동을 위한 인터페이스를 제공해야 합니다.
- **디자인 팀**: 홍보 메시지의 디자인과 사용자 경험을 개선하는 작업이 필요합니다.

## Stage 7: 지은 (수석 카피라이터 · Copywriter)
